# Archived template content

Example pages and collections from the al-folio template, kept for reference but not built into the site
(`_archive/` is listed under `exclude:` in `_config.yml`).

To bring something back, move it to its original location, e.g.

```bash
git mv _archive/_pages/teaching.md _pages/teaching.md
git mv _archive/_projects _projects
```

| Archived                                         | Original location | What it was                                                                        |

| `_pages/cv.md`                                   | `_pages/`         | Template CV page (Albert Einstein example)                                         |
| `_pages/projects.md`, `_projects/`               | `_pages/`, root   | Projects grid and 9 example projects                                               |

| `_pages/repositories.md`                         | `_pages/`         | GitHub repositories (`_data/repositories.yml`)                                     |
