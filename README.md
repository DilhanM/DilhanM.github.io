# Dilhan Manawadu's group website

Source for the Manawadu group website: quantum computational chemistry in the Department of Chemistry, University of Liverpool.

**Live site:** [dilhanm.github.io](https://dilhanm.github.io/)

## Running locally

```bash
bundle install
bundle exec jekyll serve --livereload   # http://localhost:4000/
```

Pushing to `main` builds the site and publishes it to the `gh-pages` branch via GitHub Actions.
